# Arco Clínica — prévia

Landing page estática de apresentação para a Arco Clínica. Abra `index.html` localmente para visualizar.

## Publicação na Vercel

Importe este repositório na Vercel como projeto **Other** (sem framework). O diretório raiz é `.`; não há comando de build. A Vercel servirá `index.html` e os recursos da pasta `assets/`.

Esta é uma prévia, com imagem conceitual no hero e fotos e vídeo fornecidos a partir do Instagram da clínica na galeria. Os depoimentos têm fonte documentada em `FONTES_DEPOIMENTOS.md`.
